Good to know

The rules, the words, the emails

Granted applies the rules for you. The numbers are the defaults: change them in Project Settings.

5

The rules

  • 48 hBook at least 48 hours ahead.
  • HoursWork days and gate hours only (Mon–Sat, 6 AM to 4 PM). Closed dates are blocked.
  • TrucksEach gate takes a set number of trucks per time slot.
  • PalletsEach staging zone holds a set number of pallets, from delivery until the work starts.
  • 7 daysMaterial can arrive up to 7 days before its activity starts. Earlier needs a reason and an admin's OK.
  • >20More than 20 pallets, or the same delivery twice in a week: an admin reviews it.
  • ±1 hTrucks may arrive up to an hour before or after their slot.
  • OnceA pass works once, on its own day.
  • No-showNot scanned an hour after the slot ends.

Words

Project code
(like DDC2-7HKQ). Ajax staff type it to ask to join; you approve them. Invite people from outside Ajax by email.
Admin set-up code
only for creating projects. Keep it private.
Look-ahead
the 3-week schedule of upcoming activities. Every delivery is tied to one.
Staging zone
a laydown area on site, measured in pallets.
Gate pass
the QR code and pass code (like DDC2-WFYCY9) for one delivery.
