Set up Granted · Option 1 of 2

Power Apps

Runs inside your Microsoft 365. Five steps to a working app.

{{QR_start}}
Start herethe same steps on GitHub
Have ready
  • An IT admin who is a SharePoint admin and a Power Platform admin
  • A licensed Granted account with a mailbox, e.g. granted@yourcompany.com
  • A PC with PowerShell 7 (aka.ms/powershell)
1

Run the set-up script IT admin

> git clone https://github.com/AjaxAgents/GrantedPA > cd GrantedPA > pwsh ./setup/Setup-GrantedPA.ps1

Answer its questions. It makes GrantedPA-ready.zip.

2

Make the environment IT admin

admin.powerplatform.microsoft.com→Environments→+ New: name Granted, type Production, Dataverse Yes→Save

Open it→Users→+ Add user: the Granted account as System Administrator

3

Import the app as the Granted account

make.powerapps.com→environment Granted→Solutions→Import solution→GrantedPA-ready.zip

Each connection: + New connection and sign in→Import

4

Share it

Apps→Granted→Share→Granted Users→Share

5

Open Granted

Set up your profile. Type the admin set-up code as a project code. Create the project. Invite your team from Team & Invites.

A working appBookings, approvals, QR gate passes and gate checks, on phones and browsers.

Set up Granted · Option 2 of 2

Azure

Its own small website on your Azure. Four steps to a working app.

{{QR_demo}}
Try it firstthe working demo, nothing to install
Have ready
  • Someone with Owner on an Azure subscription
1

Open Azure Cloud Shell

shell.azure.com→sign in→Bash

2

Paste this, press Enter

$ git clone https://github.com/AjaxAgents/Granted $ bash Granted/setup/azure-setup.sh
3

Answer four questions

Name, region, pilot or production, and the admin set-up code. It builds everything and prints your Granted address.

4

Open the address

Create your account. Type the admin set-up code as a project code. Create the project. Share its code with your team.

A working appBookings, approvals, QR gate passes and gate checks, in any phone browser.

The admin set-up code is never in GitHub or the app. You choose it while setting up; only a one-way hash is kept. Give it to people by phone or in person.
